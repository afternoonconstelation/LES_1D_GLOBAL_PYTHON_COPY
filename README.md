# LES_1D_GLOBAL_PYTHON

Para Usar:

1) Clonar o repositorio com o nome e local desejados. Ex: /home/jhonatan/respositories/LES_1D_GLOBAL_PYTHON
   git clone https://github.com/afternoonconstelation/LES_1D_GLOBAL_PYTHON_COPY.git

2) Adicione à variável de ambiente PYTHONPATH o caminho do programa no mesmo caminho das bibliotecas carregadas pelo python  e adicione ao .bashrc para deixá-lo acessível em todos os níves permanentemente.
   
   Ex: export PYTHONPATH=${PYTHONPATH}:/home/jhonatan/respositories/LES_1D_GLOBAL_PYTHON
